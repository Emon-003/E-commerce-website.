# 🛒 Blyynx - Premium E-Commerce Store Front

Blyynx is a modern, clean, and fully responsive dark-themed e-commerce frontend platform. Built using semantic HTML5, Tailwind CSS, and vanilla JavaScript, this project showcases a pixel-perfect user interface designed for a seamless digital shopping experience.

---

## 🚀 Live Demo
Experience the live website here: **[Blyynx Live Preview](https://emon-003.github.io/E-commerce-website./)**

---

## ✨ Features

- **Modern Dark UI:** A sleek, premium dark-themed interface crafted with fine attention to typography, spacing, and modern design trends.
- **Advanced Product Filtering:** Users can filter products dynamically in real-time by categories and custom price ranges.
- **Smart Sorting:** Features custom sorting rules (Default, Price Low-to-High, etc.) to help users find products efficiently.
- **Fully Responsive Design:** Optimized and pixel-perfect across all screen sizes, including mobile devices, tablets, and large desktops.
- **Interactive Components:** Features dynamic product cards with active "Add to Cart", "View Details", and an interactive navigation system.

---

## 🛠️ Tech Stack

- **Frontend Core:** HTML5, Vanilla JavaScript (ES6+)
- **Styling Framework:** Tailwind CSS (Utility-first CSS)
